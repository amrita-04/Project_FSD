# Budget & Expense Tracker (Full-Stack FSD Project)

A clean, modern, and minimal Full-Stack Budget & Expense Tracker built with a **Spring Boot** REST API backend and a **React + Vite** frontend.

## 📡 REST API Specification

**Base URL**: `http://localhost:8080/api/expenses`  
**CORS Origin**: Enabled for `http://localhost:5173` and `http://127.0.0.1:5173`

| HTTP Method | Endpoint | Description | Request Body | Response Status |
|-------------|----------|-------------|--------------|-----------------|
| `GET` | `/api/expenses` | Fetch all expenses & budgets | *None* | `200 OK` (Array of items) |
| `GET` | `/api/expenses/{id}` | Fetch a single expense by ID | *None* | `200 OK` / `404 Not Found` |
| `POST` | `/api/expenses` | Add a new expense or budget | JSON Object | `200 OK` (Created item with ID) |
| `DELETE` | `/api/expenses/{id}` | Delete an item by ID | *None* | `200 OK` / `404 Not Found` |

### Data Model Schema (`Expense`)
```json
{
  "id": 1,
  "title": "Monthly Budget",
  "amount": 5000.0,
  "category": "Bills",
  "type": "BUDGET"
}
```
* **id**: `Long` (Auto-generated by `AtomicLong`)
* **title**: `String` (e.g., `"Grocery Shopping"`)
* **amount**: `double` (e.g., `150.0`)
* **category**: `String` (`Food`, `Travel`, `Bills`, `Shopping`)
* **type**: `String` (`"BUDGET"` or `"EXPENSE"`)

### Pre-populated Startup Data
On startup, the backend automatically initializes 3 sample entries:
1. `id: 1` — `"Monthly Budget"` — `₹5000.0` — Category: `Bills` — Type: `BUDGET`
2. `id: 2` — `"Grocery Shopping"` — `₹150.0` — Category: `Food` — Type: `EXPENSE`
3. `id: 3` — `"Train Ticket"` — `₹45.0` — Category: `Travel` — Type: `EXPENSE`

## 🚀 How to Run the Application

### Prerequisites
* **Java 21** or later installed (`java -version`)
* **Node.js 18+** and **npm** installed (`node -v`, `npm -v`)

---

### Step 1: Start the Spring Boot Backend

Open a terminal at the project root (`Project_FSD`):

```powershell
cd backend
./mvnw.cmd spring-boot:run
```
*(On Linux/macOS, run `./mvnw spring-boot:run` or `mvn spring-boot:run`)*

The backend server will start at:  
👉 **`http://localhost:8080/api/expenses`**

---

### Step 2: Start the React Frontend

Open a **second terminal** at the project root (`Project_FSD`):

```powershell
cd frontend
npm install
npm run dev
```

The frontend development server will start at:  
👉 **`http://localhost:5173`**

Open `http://localhost:5173` in your browser to interact with the dashboard.

## 🛠️ Troubleshooting Guide

### Issue: `Process terminated with exit code: 1` during `spring-boot:run`
If you encounter this error:
```
[ERROR] Failed to execute goal org.springframework.boot:spring-boot-maven-plugin:...:run ... Process terminated with exit code: 1
```

#### Cause 1: Port 8080 is already occupied (Most Common)
Another process or a previously started backend instance is still holding port `8080`.

**Solution**:
1. Check what is running on port 8080:
   ```powershell
   netstat -ano | findstr :8080
   ```
2. Note the PID (the number at the far right) and terminate it:
   ```powershell
   taskkill /PID <PID> /F
   ```
3. *Alternative*: Change the port in `backend/src/main/resources/application.properties`:
   ```properties
   server.port=8081
   ```
   And update `API_BASE_URL` in `frontend/src/App.jsx` to `http://localhost:8081/api/expenses`.

#### Cause 2: Reveal the Hidden Error with `-e`
Maven hides the internal stack trace by default. Re-run Maven with the `-e` flag to inspect the exact failure reason:
```powershell
cd backend
./mvnw.cmd clean spring-boot:run -e
```
Inspect the logs right before `[INFO] ---` to find the exact exception.

#### Cause 3: Java Version Check
Ensure your terminal is using Java 21 or later matching `pom.xml`:
```powershell
java -version
```
If your system points to an older JDK (e.g. Java 8 or 17), set `JAVA_HOME` to your JDK 21 installation path.

## ✨ Features Included

1. **Live Summary Cards**:
   * Total Budget, Total Spent, and Remaining Balance dynamically computed and formatted in Indian Rupees (`₹`).
2. **Visual Budget Utilization Bar**:
   * Displays the percentage of budget spent.
   * Dynamically turns **green** (`<= 85%`), **amber** (`85-100%`), or **red** (`> 100%`) with an explicit over-budget warning when expenses exceed the budget.
3. **Category Breakdown Summary**:
   * Displays total spending and percentage share across all categories (**Food**, **Travel**, **Bills**, **Shopping**).
   * Interactive click-to-filter capability.
4. **Category Filter Dropdown**:
   * Filter transactions by any category or view all.
5. **Add Entry Form**:
   * Form with Title, Amount (₹), Type (`Budget` / `Expense`), and Category dropdown.
   * Validates input and triggers a `POST /api/expenses` request.
6. **Instant Delete**:
   * Delete button per entry that issues a `DELETE /api/expenses/{id}` request and updates the UI immediately.
7. **Connection Status & Error Handling**:
   * Displays a loading spinner on startup.
   * Shows a graceful error card with a **"Retry Connection"** button if the backend server is offline or restarting.
